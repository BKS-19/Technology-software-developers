# Практическая работа №2

Адаптивный каталог из 18 учебных товаров. Карточки расположены через Grid, шапка и содержимое карточек используют Flexbox. Стили написаны на SCSS и скомпилированы в CSS. Фильтры работают на обычном JavaScript.

## Запуск

Для просмотра достаточно открыть `index.html` в браузере. Готовый `css/styles.css` хранится в репозитории, поэтому устанавливать зависимости только для просмотра не нужно.

Для изменения стилей нужны Node.js версии 20.19 или новее и npm.

После клонирования репозитория:

```bash
git clone https://github.com/BKS-19/Technology-software-developers.git
cd Technology-software-developers/pr2
npm ci
npm run build
```

Откройте `pr2/index.html` в браузере. Если уже находитесь в папке `pr2`, открывайте `index.html` из неё.

Разовая сборка:

```bash
npm run build
```

Автоматическая сборка при изменении SCSS:

```bash
npm run watch
```

После сохранения SCSS обновите страницу в браузере. Остановить наблюдение можно сочетанием Ctrl+C.

## Данные

Названия, категории, цены и рейтинги всех 18 карточек вручную перенесены из `dataset/catalog.csv` в HTML. Поле `id` записано в `data-id`. Для каждой категории используется одно из трёх изображений из набора задания.

Категория, цена и рейтинг также записаны в атрибутах `data-category`, `data-price` и `data-rating`. Скрипт `js/catalog.js` читает эти значения и скрывает карточки, которые не подходят под выбранные условия. Несколько выбранных категорий объединяются, а цена и рейтинг дополнительно ограничивают результат. Если категории не выбраны, показываются товары всех категорий.

Основные цвета, радиус 14px и базовый отступ 16px перенесены из `dataset/theme.json` в `scss/_variables.scss`. Автоматической загрузки CSV и JSON в браузере нет. При изменении CSV нужно обновить карточки и границы фильтров; при изменении темы — переменные SCSS и затем выполнить сборку.

## Организация SCSS

`styles.scss` подключает модули через `@use`. В `_base.scss` находятся базовые правила, в `_layout.scss` — раскладка страницы, в `_components.scss` — оформление фильтров, кнопок и карточек.

SCSS-переменная, например `$accent`, обрабатывается во время компиляции. В CSS вместо неё попадает готовое значение. Для изменения результата нужно пересобрать CSS. CSS custom property, например `--accent`, остаётся в CSS, участвует в каскаде и может меняться в браузере без компиляции.

Partial-файлы начинаются с подчёркивания. Они разделяют стили на небольшие части и подключаются к основному файлу, не создавая отдельный CSS для каждой части.

Mixin `panel` в `_mixins.scss` задаёт общий фон, отступ и радиус для фильтров, карточек, информационного блока и сообщения о пустом результате. Mixin `container` ограничивает ширину основного содержимого.

Функция `space($step)` в `_functions.scss` умножает базовый отступ на переданный коэффициент. Например, `space(0.5)` даёт 8px, а `space(1.5)` — 24px. Поэтому интервалы можно изменить через одну переменную `$space`.

Вложенность используется для элементов компонентов и состояний `:hover`. Глубина не превышает трёх уровней.

Документация Sass: [подключение модулей](https://sass-lang.com/documentation/at-rules/use/), [компиляция и режим наблюдения](https://sass-lang.com/documentation/cli/dart-sass/).

## Адаптивность

При ширине больше 900px фильтры находятся слева от каталога. На ширине 900px и меньше они переносятся над карточками. До 480px включительно карточки располагаются в две колонки с уменьшенными отступами и шрифтом.

## Проверка

1. Откройте страницу: должны отображаться 18 товаров и счётчик «18 из 18».
2. Выберите «Книги» и нажмите «Применить»: останется 6 товаров.
3. Нажмите «Сбросить»: снова появятся все товары, поля очистятся.
4. Выберите «Книги», цену от 800 до 1500 и рейтинг от 4.5: останутся товары 4 и 10.
5. Сбросьте фильтры и задайте цену от 2010 до 2010: появится сообщение, что ничего не найдено.
6. Задайте цену от 1500 до 1000: появится ошибка диапазона, карточки не изменятся. Исправьте значения и повторите фильтрацию.
7. Проверьте ограничения полей: цена 100 должна отклоняться браузером, так как минимум равен 575.
8. В Responsive Mode проверьте ширины 375, 768 и 1440px: горизонтальной прокрутки быть не должно, изображения и поля должны помещаться в свои блоки.
9. Проверьте Console и Network: скрипт, CSS и изображения должны загружаться без ошибок.

В Chromium проверены ширины 375, 768 и 1440px: горизонтальной прокрутки нет. На 375px отображаются две колонки карточек, на 768 и 1440px — три. Проверены совместное применение фильтров, сброс, пустой результат, ошибка диапазона, ограничения цены и открытие страницы напрямую с диска. Ошибок JavaScript и загрузки ресурсов не обнаружено.

Этапы работы: сначала добавлены карточки и CSS, затем переменные, короткая вложенность, partial-файлы, mixin и функция отступов. После переноса стилей настроена сборка, проверена сетка и два breakpoint. Далее добавлены фильтры, обработка неверного диапазона и пустого результата.
