# Академический пример к практической работе 1

## Назначение

Этот пример предназначен для разбора принципа, а не для копирования итогового решения. Основная практическая работа выполняется на собственном наборе данных из папки `dataset`.

## Учебный кейс

**Учебная конференция «Цифровой университет»**

На примере одной статической страницы показать связь семантики HTML и визуального оформления CSS. Студент сначала собирает документ из смысловых блоков, затем оформляет их стилями.

## Что изучить до запуска

- HTMLBook HTML — https://htmlbook.ru/samhtml
- HTMLBook CSS — https://htmlbook.ru/samcss

## Логика разбора

1. Определить смысловую структуру страницы до написания CSS.
2. Связать пункты навигации с id разделов.
3. Собрать повторяющиеся карточки с единым набором классов.
4. Создать таблицу с заголовком и телом.
5. Создать форму с label и встроенными ограничениями HTML.
6. Добавить Flexbox и медиазапрос.
7. Проверить семантику, клавиатурную навигацию и доступные имена элементов.

## Ожидаемое наблюдение

В браузере видна страница с логичной иерархией заголовков. Переход по ссылке «Расписание» приводит к таблице. При ширине около 700 px карточки перестраиваются, а форма остаётся читаемой.

## Что сделать по аналогии

Реализуйте тот же технический принцип для основной работы, но используйте её dataset, собственные имена сущностей и собственную структуру. После реализации сравните своё приложение с `example-result.png` не по цветам, а по наличию требуемых состояний, данных и пользовательских сценариев.

## Что студент должен уметь объяснить

- откуда поступают входные данные
- где они преобразуются
- какой код отвечает за отображение
- какое ошибочное состояние предусмотрено
- почему выбранная структура не смешивает несвязанные обязанности
