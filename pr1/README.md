Информационная страница учебного курса **TRPO Course**, сверстанная на чистых HTML и CSS по данным из dataset.

## Структура страницы

- `header` — логотип, заголовок `h1` и навигация `nav`
- `main` — четыре раздела `section`:
  - `#about` — О курсе: описание и обложка
  - `#tracks` — Направления: 6 карточек `article.card`
  - `#schedule` — Расписание: таблица с `thead` и `tbody`
  - `#signup` — Регистрация: форма записи на курс
- `footer` — подвал

## Использованные данные (dataset)

| Файл | Где используется |
|---|---|
| `data/navigation.json` | пункты меню; поле `target` — это `id` разделов, `label` — текст ссылок |
| `data/content.csv` | 6 карточек направлений, строки таблицы, варианты в списке формы |
| `images/logo.svg` | логотип в шапке |
| `images/cover.svg` | обложка в разделе «О курсе» |

Файлы dataset не изменялись. Данные перенесены в HTML вручную.

## Форма

- у каждого поля есть `label`, связанный с полем через `for` / `id`
- типы полей: `text`, `email`, `number`, `select`, `textarea`
- ограничения: `required`, `minlength`, `maxlength`, `min` / `max` для возраста

## CSS-приёмы

- `box-sizing: border-box` для всех элементов
- базовая типографика и цвета задаются в `body`
- ограничивающий контейнер: `main` с `max-width` и `margin: auto`
- Flexbox: шапка, меню и карточки с переносом (`flex-wrap`)
- медиазапрос `@media (max-width: 720px)` для мобильных экранов
- `:focus-visible` — заметный фокус при навигации клавишей Tab
- `:user-invalid` — красная рамка у неверно заполненных полей
- стили только через классы и теги, без `style` в HTML
